## GL Bajaj CDC: Summer Vacation Self-Learning Assignments

Welcome to my repository containing solutions for the **Summer Vacation Self-Learning Assignments** assigned by the **Career Development Centre (CDC)** at **G L Bajaj Institute of Technology and Management**. 

This comprehensive 30-day coding track is curated to master fundamental programming logic, data structures, algorithms, and modular design patterns targeting top-tier product and service-based companies.

---

## 🚀 Key Highlights
* **Language Used:** Java (with clear emphasis on optimized time & space complexity)
* **Target Companies Covered:** TCS, Infosys, Wipro, Amazon, Microsoft, Deloitte, Adobe, Capgemini, Accenture, Cognizant, and Paytm.
* **Structure:** 120 algorithmic problems and mini-projects distributed across a structured 30-day curriculum.
